Yo gaes ini project sederhana buat kalian yang mau MODIFIKASI dispenser di rumah biar jadi OTOMATIS!
Caranya cukup gampang, siapin:
- Arduino UNO (x1)
- Sensor Ultrasonik HC-SR04 (x3)
- Motor Servo MG996R (x3)
- Baterai AA 1,5 volt (x4)git
- Kabel jumper male-female
